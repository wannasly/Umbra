# Security policy

## Supported versions

Исправления безопасности выпускаются для последней опубликованной версии Umbra.

## Как сообщить об уязвимости

Используйте **Security → Report a vulnerability** в GitHub-репозитории. Не публикуйте уязвимость в открытом issue до согласования исправления.

Никогда не прикладывайте настоящую ссылку подписки, токен, `profiles.json`, `settings.json` или полный сгенерированный конфиг. Замените адреса, UUID и идентификаторы на заведомо тестовые значения. Если для воспроизведения нужен секрет, сначала дождитесь ответа сопровождающего.
