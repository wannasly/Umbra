# Bundled fonts

The interface uses Inter 400/500/600 for controls and body text, Manrope 800
for display headings, and JetBrains Mono 500 for technical values. Body text
uses weight 500 so small Cyrillic labels retain clear, even strokes at desktop DPI.

Manrope Regular, Medium and SemiBold are static instances of the Google Fonts
Manrope variable font (`wght` = 400, 500, 600), generated with fontTools:
https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf

All fonts are bundled locally, including Cyrillic glyphs; no runtime download
is required. License texts are in the adjacent `*-OFL.txt` files.
