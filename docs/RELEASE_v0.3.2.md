# Umbra 0.3.2 — подписки и выбор сетевого ядра

- Исправлена форма добавления подписки: отдельная кнопка вставляет URL из буфера обмена, адрес проверяется до отправки.
- Добавлен выбор Mihomo или sing-box. Выбранное ядро используется для системного прокси и TUN при следующем подключении.
- Настройки показывают доступность и версии обоих ядер; загрузка, проверка совместимости, конфигурация и запуск теперь следуют выбранному ядру.
- Оба ядра входят в установщик и portable-архив. GitHub Actions загружает закреплённые версии, проверяет SHA-256 и проверяет содержимое пакетов и установку.
- Улучшена отрисовка встроенных шрифтов и кириллицы в программном рендерере; уточнены подписи и подсказки на русском и английском.
- Добавлены уведомления о лицензии Mihomo и локальных копиях ядер в документацию.

Перед обновлением отключитесь и завершите Umbra через меню в трее. Настройки и профили сохраняются. Для установки скачайте `Umbra_0.3.2_x64-setup.exe`; для запуска без установки — `Umbra_0.3.2_windows_x64_portable.zip`. SHA-256 файлов опубликованы в `SHA256SUMS.txt`.
