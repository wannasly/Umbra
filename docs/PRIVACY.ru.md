# Приватность Umbra

Umbra не использует аккаунт разработчика, аналитику, рекламные SDK и телеметрию.

## Какие данные хранятся

Приложение сохраняет локально в `%APPDATA%\com.umbra.proxy`:

- `profiles.json` — импортированные серверы и ссылки подписок;
- `settings.json` — настройки, правила маршрутизации и локальный HWID;
- `generated.json` — временная конфигурация sing-box;
- локальную копию `sing-box.exe`.

Эти файлы не синхронизируются с репозиторием или серверами Umbra. Ссылка подписки передаётся только указанному в ней серверу провайдера при обновлении. HWID отправляется провайдеру только если соответствующая настройка включена.

## Сетевые обращения

Umbra обращается к сети для:

- загрузки и обновления пользовательских подписок;
- проверки задержки серверов и работы соединения;
- проверки и загрузки sing-box с официальных релизов `SagerNet/sing-box` на GitHub.

После подключения трафик обрабатывает локальный процесс sing-box по выбранной пользователем конфигурации.

## Перед публикацией отчёта

Не прикладывайте `profiles.json`, `settings.json` и `generated.json` целиком. Удалите из журналов ссылки подписок, UUID, домены серверов, IP-адреса и HWID. В шаблоне issue предусмотрено отдельное подтверждение этой проверки.
