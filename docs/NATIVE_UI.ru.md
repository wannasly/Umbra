# Перенос интерфейса Umbra на Rust

## Выбор UI

Исходник для сравнения: Tauri + React версии 0.2.5, коммит f93df33. Старая версия сохранена в истории Git и отдельной рабочей копии; новый код разрабатывается в ветке codex/umbra-native-slint.

| Вариант | Воспроизведение исходного дизайна | Обновление экрана | Решение |
| --- | --- | --- | --- |
| egui | Возможны собственные отрисовка и шрифты, но обычные widgets не повторяют исходную компоновку; первый прототип не соответствовал оригиналу | Immediate mode; требует осторожного управления repaint | Прототип заменён |
| Slint | Декларативная компоновка, собственные компоненты, SVG, градиенты, состояния и переходы, виртуальные списки | Retained mode: изменяются только затронутые свойства | Используется в новой версии |

Новая Windows-сборка не зависит от Tauri, Wry, WebView2 или egui. Бэкенд Rust и формат пользовательских данных сохранены.

Перед созданием UI проверяются необходимые функции OpenGL в кратковременном скрытом контексте Windows. На базовом видеодрайвере без поддержки шейдеров выбирается программный рендер Slint; совместимые драйверы используют FemtoVG. Контекст и окно проверки освобождаются сразу. Для диагностики можно явно задать `UMBRA_RENDERER=software`.

## Исходный дизайн

Перенесены исходная морская палитра, Inter 400/500/600, Manrope 800, JetBrains Mono 500, радиусы панелей и controls, Lucide и флаги. Изучены Sidebar, Titlebar, Dashboard, Servers, Subscriptions, Routing, Settings, Logs и общие компоненты исходной версии.

- Главная: круг подключения, имя и характеристики узла, задержка, режим, трафик и график.
- Серверы: избранное, группы и подписки, уведомления провайдера, поиск, сортировка и меню.
- Подписки: URL, квота, срок, автообновление, кабинет и поддержка.
- Маршруты: default route, предупреждение о TUN, фильтры, правила и редактор.
- Настройки: исходные разделы, строки и значения; журнал — фильтры и ограниченный виртуальный список.
- Узкое окно: нижняя навигация и перенос controls на отдельные строки.

Отрисовка текста и размытия у Chromium и Slint различается. Воспроизводится исходная композиция, а не обещается попиксельная идентичность. Декоративные бесконечные движения фона и волны заменены статичным кадром, чтобы не перерисовывать простой. Переходы controls сохраняются.

## Бэкенд и жизненный цикл

Существующие команды вызываются напрямую из диспетчера Rust, без IPC/WebView. Сетевые операции выполняются в Tokio; UI получает объединённые события. Трей работает в UI-потоке Windows. Скрытое окно продолжает обслуживать приложение, повторный запуск сигнализирует первой копии.

Настройки и профили используют прежний каталог %APPDATA%/com.umbra.proxy. Перед запуском ядра завершается восстановление системного прокси. На выходе ядро останавливается. Журнал ограничен 2000 строками и обновляется на видимой странице; списки серверов и правил виртуализированы.

## Измерение ресурсов 23.10.2026

Обе release-сборки запускались отдельно с одинаковыми тестовыми profiles/settings и окном 1280×720 logical. После 7 секунд прогрева измерялось 30 секунд без подключения. Для Tauri суммировались 7 процессов, для Slint — один. Сборка Rust в момент замера не выполнялась.

| Среднее в выборке | Tauri 0.2.5 | Slint |
| --- | ---: | ---: |
| Private working set | 205,44 МиБ | 63,80 МиБ |
| Working set | 485,31 МиБ | 114,85 МиБ |
| CPU, один логический процессор = 100% | 166,844% | 0,151% |
| CPU всей машины, 16 логических процессоров | 10,427% | 0,009% |
| GPU engines, сумма | 2,59% | 0,00% |
| GPU dedicated | 67,03 МиБ | 62,20 МиБ |
| GPU shared | 5,26 МиБ | 19,66 МиБ |

CPU приведён после округления за короткое окно; отсутствие загрузки GPU в выборке не означает абсолютно нулевой расход при любом использовании. Видеопамять в сумме увеличилась примерно на 10 МиБ. Это измерение простоя на одном компьютере: оно не описывает максимальную нагрузку ядра, сетевой трафик и все драйверы GPU.

## Проверки

[Снимки всех шести экранов при 1280×720 и 480×960, оригинал и Slint рядом](VISUAL_COMPARISON.ru.md).

Автоматические тесты покрывают сохранённый бэкенд и нативные команды. Отдельный opt-in тест с настоящим sing-box проверяет VLESS, Direct, Block, системный прокси и HTTP через настоящий TUN, затем останавливает всё и восстанавливает настройки. Снимки оригинала и Slint сравниваются при одинаковом физическом размере.

Проверка на машине с уже повышенными правами не заменяет ручную проверку появления и отмены UAC под обычным пользователем. Публичные провайдеры и настоящие подписки не используются в автоматических тестах. Процедуры воспроизведения и дополнительные сценарии: [TESTING.ru.md](TESTING.ru.md).


Эталонный замер Tauri сохранён ранее в этой сессии. Финальная Slint-сборка измерена отдельно; уже работающая пользовательская Umbra при повторных проверках не завершалась.
