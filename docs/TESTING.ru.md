# Проверка Umbra перед релизом

## Автоматические проверки

```powershell
npm ci
npm run build
$env:CARGO_TARGET_DIR = Join-Path $env:TEMP 'umbra-test-target'
cargo test --manifest-path src-tauri/Cargo.toml
```

## Ручной smoke-test

- добавить тестовую подписку и отдельную `vless://`-ссылку;
- обновить подписку, проверить лимиты и список серверов;
- проверить задержку, избранное, поиск и переключение сервера;
- подключиться через системный прокси и убедиться, что он восстановлен после отключения;
- подключиться через TUN после UAC и проверить прямое, проксируемое и блокирующее правило приложения;
- проверить трей, повторный запуск, автозапуск и восстановление после аварийного завершения ядра;
- проверить русский и английский интерфейс в широком и вертикальном окне;
- убедиться, что в нижней панели вертикального режима отображаются только иконки.

Используйте только тестовые подписки и адреса. Перед публикацией журналов удалите URL, UUID, IP, домены и HWID.
