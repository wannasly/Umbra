# Проверка нативной Umbra

## Автоматические проверки

~~~powershell
cargo fmt --all -- --check
cargo test --workspace --locked
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
cargo build --release --locked
~~~

Тесты проверяют парсеры, ядро, генерацию маршрутов, миграции, сохранение профилей, подписки с локальным HTTP-провайдером, команды UI и компоненты Slint. Сетевой тест настоящей подписки пропущен по умолчанию: он требует UMBRA_LIVE_SUB_URL.

## Реальное ядро, системный прокси и TUN

На свободной Windows-машине с повышенными правами и src-tauri/resources/sing-box.exe:

~~~powershell
cargo test --lib real_core_proxy_routing_tun_and_cleanup -- --ignored --nocapture --test-threads=1
~~~

Тест отказывается работать при включённом системном прокси или существующем umbra-tun. Запускает локальный VLESS-сервер и два HTTP-сервера, проверяет различающиеся ответы Proxy / Direct, отказ Block и передачу HTTP через настоящий TUN. Маршрут по умолчанию — Direct.

В конце, включая падение сценария, тест останавливает ядро и восстанавливает WinINET. Логи и резервная копия настроек остаются в artifacts/native/live-*. После теста проверьте отсутствие тестового адаптера и процессов ядра.

## Снимки экранов

~~~powershell
./scripts/visual-smoke.ps1
./scripts/visual-smoke.ps1 -NoBuild -Size 480x960
./scripts/visual-smoke.ps1 -NoBuild -Pages dashboard -Status connecting
./scripts/visual-smoke.ps1 -NoBuild -Pages dashboard -Status connected
~~~

Скрипт собирает диагностическую release-версию, запускает каждую страницу с отдельными данными из tests/fixtures/visual, сохраняет изображение штатным renderer Slint и завершает приложение. Настоящие профили пользователя не используются. Параметр `-Status` меняет только отображение для снимка: ядро и сетевое подключение не запускаются. Снимки — в artifacts/native/slint-&lt;размер&gt;/.

Сохраняйте снимки исходного React-интерфейса при том же фактическом размере viewport. Сравнивайте заголовки, границы панелей, отступы, кнопки, списки, меню и диалоги. Проверяйте оба языка, длинные имена и пустые списки при 480×960, 720×500, 1100×720 и 1280×720. Подписи, значения и кнопки не должны накладываться.

## Проверка движения

~~~powershell
./scripts/visual-smoke.ps1 -NoBuild -Pages dashboard -Status connected -Traffic
./scripts/visual-smoke.ps1 -NoBuild -Pages servers -Scroll
./scripts/motion-bench.ps1 -Scene dashboard
./scripts/motion-bench.ps1 -NoBuild -Scene pages
./scripts/motion-bench.ps1 -NoBuild -Scene resize
~~~

Сцены используют только локальные фикстуры и синтетический трафик, без сетевого соединения. Для сравнения кадров не запускайте сборку или несколько сцен одновременно. Первые две секунды исключены из замера. В сцене страниц учитываются интервалы, перед которыми шла анимация, а не намеренные паузы между переходами. Отчёт `frame-times.json` содержит FPS, медиану, p95/p99 и исходные интервалы. Это интервалы завершения отрисовки на текущей машине, а не измерение частоты физического вывода дисплеем и не гарантия для любого устройства. Параметр `-Scale 1.25` позволяет повторить замер при масштабе 125%.

Вручную проверьте изменение размера за все четыре края и углы, перетаскивание полосы прокрутки, колесо и «Меньше анимаций». Программная смена размера в сцене не заменяет проверку захвата краёв мышью.

## Ресурсы

~~~powershell
./scripts/measure-resources.ps1 -RootProcessId <PID> -Seconds 30 -Output artifacts/native/resources.json
~~~

Измеряются приватный и общий рабочий набор, commit, CPU и счётчики GPU по дереву процессов. Для Tauri включайте дочерние WebView2. Используйте одинаковые данные, окно, DPI и состояние соединения; не измеряйте одновременно со сборкой. Проверяйте видимое окно и свёрнутый трей. При подключении учитывайте ядро sing-box у обеих версий.

## Перед публикацией

Тест `dropdown_options_have_hit_areas_and_dispatch_selection_on_pointer_click` нажимает мышью на сортировку, интервал подписки, действие маршрута и стратегию DNS, проверяет закрытие списка и обновлённое значение после сохранения. Он также проверяет выбор пункта меню действий сервера. Вручную дополнительно проверьте положение панели у нижнего края окна и выбор с клавиатуры.

- Подписки: добавление, обновление, переименование, удаление и сохранение.
- Серверы: импорт, выбор, избранное, поиск, сортировка и задержка.
- Маршруты: имя/путь процесса, домен, CIDR, порядок, отключение и удаление, сообщение о переподключении.
- Настройки после перезапуска, трей, повторный запуск и автозапуск.
- Подключение, восстановление прокси, TUN, UAC, остановка и аварийное завершение ядра.
- Установщик и portable-архив, ядро, лицензии и контрольные суммы.
- Успешные проверки и Windows-сборка в GitHub Actions.

Не публикуйте настоящие URL подписок, UUID, HWID и личные логи. Для снимков используйте фикстуры.
