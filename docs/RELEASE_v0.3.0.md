# Umbra 0.3.0 — нативный Rust-интерфейс

Интерфейс перенесён с Tauri + React на Slint. WebView2 и Node.js для запуска не нужны. Сохранены исходная композиция Umbra, палитра, шрифты, панели и основные сценарии работы.

- Существующий Rust-бэкенд, VLESS/Reality, Hysteria2, sing-box 1.13.14, системный прокси и TUN.
- Подписки, квоты, HWID, профили, избранное, поиск и задержка.
- Маршруты процессов, доменов и IP/CIDR; Proxy / Direct / Block.
- Нативный трей, возврат окна при повторном запуске, настройки и журнал.
- Исправлена адаптивная компоновка узких окон: подписи и кнопки размещаются без наложений.
- На базовом видеодрайвере Windows без нужных функций OpenGL автоматически используется программный рендер.

Прежние настройки и профили из `%APPDATA%\com.umbra.proxy` сохраняются. Перед обновлением завершите старую копию через трей. Старая Tauri-версия остаётся доступна в релизе v0.2.5.

В локальном 30-секундном замере простоя приватный рабочий набор снизился с 205,44 до 63,80 МиБ, примерно на 69%. CPU всей тестовой машины: 10,427% и 0,009%; GPU engines: 2,59% и 0% в выборке. При этом суммарная видеопамять Slint выше примерно на 10 МиБ. Это измерение одного сценария, а не гарантия расхода на любой машине; методика и сырые результаты находятся в документации.

Фон и декоративная волна статичны в простое, переходы controls сохранены. Не используется постоянная перерисовка неподвижного UI.

Проверки включают тесты Rust/Slint, локальный VLESS-сервер, реальные маршруты Proxy / Direct / Block и HTTP через настоящий TUN с последующим восстановлением системного прокси. Исходный и новый интерфейсы сравнивались при одинаковых размерах окна. Проверка TUN выполнялась с уже повышенными правами; появление и отмена UAC под обычным пользователем остаются отдельным ручным сценарием.

Для установки скачайте `Umbra_0.3.0_x64-setup.exe`. Для запуска без установки — `Umbra_0.3.0_windows_x64_portable.zip`. В архив входит ядро sing-box. Контрольные суммы — `SHA256SUMS.txt`. Сборки не подписаны коммерческим сертификатом.
