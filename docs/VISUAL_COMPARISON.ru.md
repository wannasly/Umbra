# Сравнение интерфейсов

Слева — исходная Tauri + React 0.2.5, справа — нативная Slint 0.3.0. Используются тестовые профили из исходного браузерного preview. Фактические размеры каждой пары совпадают. Динамические даты обновления и время журнала могут различаться. В узкой главной исправлено обтекание пояснения режима, которое переполняло исходный интерфейс.
