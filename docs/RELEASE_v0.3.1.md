# Umbra 0.3.1 — плавность и исправления интерфейса

- Обновлены переходы между страницами, движение индикатора навигации, переключатели и кнопка подключения.
- График трафика получил плавные кривые, движение между обновлениями и постепенное изменение масштаба. Подготовка изображения вынесена из потока интерфейса.
- Уточнены шрифты и насыщенность небольших надписей, включая кириллицу.
- Добавлена тонкая полоса прокрутки с перетаскиванием, колесом и управлением с клавиатуры.
- Увеличен начальный размер окна с учётом рабочей области экрана и DPI; восстановлена нативная возможность изменения размера окна Windows.
- Исправлены выпадающие списки в подписках, маршрутизации и настройках, сортировка и меню действий сервера: панели отображаются полностью, пункты принимают клики, выбранные значения сохраняются.
- Настройка «Меньше анимаций» сохранена.

Проверки включают тесты Rust/Slint с нажатиями мыши на пункты меню и сохранением выбранных значений. GitHub Actions собирает и проверяет установщик и portable-архив перед публикацией.

Для установки скачайте `Umbra_0.3.1_x64-setup.exe`. Для запуска без установки — `Umbra_0.3.1_windows_x64_portable.zip`. В комплект входит sing-box 1.13.14; контрольные суммы находятся в `SHA256SUMS.txt`.

Перед обновлением завершите предыдущую версию через меню в трее. Существующие настройки и профили сохраняются.
